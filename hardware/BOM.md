Bill of Materials (BOM)

1. ESP8266 NodeMCU (e.g., NodeMCU v1.0) - 1
2. Sound detection module (analog) - 1
   - e.g. "Microphone Sound Sensor Module" (operates on 3.3V)
3. Rain/Wet sensor (digital + analog outputs) - 1
4. Servo motor (micro, e.g., SG90) - 1
5. Active buzzer - 1
6. Breadboard + jumper wires
7. USB A to Micro USB cable (for power & programming)
8. Optional: external 5V supply/regulator for servo if using 5V servo

Notes:
- Check servo voltage spec (some require 5V). If so, use external 5V supply with common ground.
- Use resistors/transistor driver for buzzer if it draws more than MCU GPIO can provide.
